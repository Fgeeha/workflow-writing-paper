# Рубрика: артефакт «план экспериментов»

Порог принятия: 7.0
Обязательные разделы: Эксперименты; Базовые линии; Ключи реестра; Риски

| Код | Критерий | Вес |
|---|---|---|
| C1 | Каждое утверждение новизны покрыто экспериментом с метрикой и критерием опровержения | 0.35 |
| C2 | Базовые линии честны и воспроизводимы; число прогонов и сидов достаточно для вывода | 0.25 |
| C3 | Каждое измеряемое число имеет ключ реестра `snake_case` с единицей и источником | 0.25 |
| C4 | Риски и порядок выполнения названы; нет планов, невыполнимых на заявленных ресурсах | 0.15 |

Блокер — утверждение новизны без эксперимента; эксперимент без метрики или критерия; выдуманный результат.
