# Рубрика: артефакт «новизна»

Порог принятия: 7.0
Обязательные разделы: Формулировки новизны; Исследовательские вопросы; Гипотезы; Утверждения; Возражения; Журналы

| Код | Критерий | Вес |
|---|---|---|
| C1 | Формулировки новизны конкретны, различаются по силе и не выходят за материалы автора | 0.3 |
| C2 | У каждой гипотезы есть критерий опровержения; вопросы отвечают на «что нового» | 0.3 |
| C3 | Каждое утверждение снабжено указанием, чем будет подтверждено | 0.2 |
| C4 | Возражения рецензента правдоподобны, ответы на них по существу; нет выдуманных чисел | 0.2 |

Блокер — утверждение или число, которого нет в материалах автора, либо гипотеза без критерия опровержения.
